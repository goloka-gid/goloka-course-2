## Что исправлено относительно Курса 1

1. **`loadContent('final')` баг убран** — в Курсе 1 в `finalCard.onclick` вызывалась несуществующая функция. Здесь этого вызова нет — финальная карточка просто открывает меню.
2. **Картинка финала исправлена** — в Курсе 1 для `currentDayNum === 'final'` код искал `images/dayfinal.jpg` (которого не существует). Здесь используется `images/final.jpg` — как уже было правильно сделано в song-секции.
3. **Жёстко зашитое "10 дней" заменено на `items.length`** — теперь любой количество дней работает без правок логики. Можно сделать 7, 14, 21 день — просто измени `data.js`.
4. **`google_apps_script.js` теперь реально работает** — в Курсе 1 в репозитории была только заглушка `doPost`, без обработки `getProgress`. Здесь полная версия с обоими обработчиками + админ-функциями для одобрения/возврата ДЗ.

## Шаг 1. Создай новый репозиторий на GitHub

1. Зайди на https://github.com/new
2. Repository name: `goloka-course-2` (или как хочешь)
3. Public

## Шаг 2. Загрузи каркас

Распакуй этот ZIP в папку, затем:

```bash
cd goloka-course-2-scaffold
git init
git add .
git commit -m "initial: scaffold for course 2"
git branch -M main
git remote add origin https://github.com/goloka-gid/goloka-course-2.git
git push -u origin main
```

## Шаг 3. Включи GitHub Pages

1. В репозитории: Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main` / `root`
4. Save
5. Через минуту получишь URL вида `https://goloka-gid.github.io/goloka-course-2/`

## Шаг 4. Создай новый Apps Script (Вариант B)

**Цель:** отдельный скрипт в той же Google-таблице, пишет в отдельный лист.

1. Открой существующую Google-таблицу (где сейчас лежат ответы Курса 1)
2. Меню: **Extensions → Apps Script**
3. В редакторе: **File → New Project** (или просто создай новый файл в существующем проекте)
4. Скопируй всё содержимое файла `google_apps_script.js` из этого каркаса
5. Вставь в новый файл проекта, сохрани (Ctrl+S)
6. Назови проект, например, `Course2_Backend`
7. **Deploy → New deployment**
   - Type: Web app
   - Description: `Course 2 backend v1`
   - Execute as: **Me**
   - Who has access: **Anyone**
8. Нажми **Deploy**
9. Авторизуйся (Google попросит доступ к таблице — разреши)
10. Скопируй URL вида `https://script.google.com/macros/s/AKfycb...ДРУГОЙ_ID.../exec`

## Шаг 5. Подставь URL в код

Открой `app.js`, найди строку (ближе к началу):

```js
const GOOGLE_APP_SCRIPT_URL = "https://script.google.com/macros/s/ЗАМЕНИТЕ_НА_ВАШ_НОВЫЙ_URL/exec";
```

Замени `ЗАМЕНИТЕ_НА_ВАШ_НОВЫЙ_URL` на свой URL из шага 9.

Закоммить и запушь:
```bash
git add app.js
git commit -m "config: set Apps Script URL"
git push
```

## Шаг 7. Наполни контент

Для каждого дня N (1, 2, 3, ...) нужно создать файлы:

| Файл | Кнопка в меню | Описание |
|---|---|---|
| `texts/dayN_story.html` | 📖 Сказочная история | Сказка дня с `[IMAGE]`, `[VID1]`-`[VID4]` маркерами |
| `texts/dayN_child.html` | 👶 Практика для детей | Детская медитация |
| `texts/dayN_adult.html` | 🧘‍♀️ Практика (Взр) | Взрослая медитация |
| `texts/dayN_homework.html` | ✍️ Домашнее задание | С маркерами `[ВОПРОС]` для разделения вопросов |
| `texts/dayN_presentation.html` | 🖼️ Презентация | HTML со слайдами, путь к картинкам: `images/present/dayN/1.webp` |

Дополнительно (опционально):
| Файл | Описание |
|---|---|
| `audio/dayN_story.mp3` | Озвучка истории |
| `audio/dayN_child.mp3` | Озвучка детской практики |
| `audio/dayN_adult.mp3` | Озвучка взрослой практики |
| `audio/dayN_song.mp3` | Песенка дня |
| `images/dayN.jpg` | Главная картинка дня |
| `images/present/dayN/1.webp` ... `15.webp` | Слайды презентации (15 шт.) |

**Видео НЕ используется** в этом курсе (отключено в каркасе). Если в `texts/dayN_story.html` ты используешь маркеры `[VID1]`, `[VID2]` — видео-файлы должны лежать в `videos/dayN_1.mp4` и т.д., но кнопки «🎬 Видео» в меню не будет.

Для **финального дня** (когда пользователь прошёл все дни):
| Файл | Описание |
|---|---|
| `texts/final_story.html` | Финальная история |
| `texts/final_child.html` | Финальная детская медитация |
| `texts/final_adult.html` | Финальная взрослая медитация |
| `texts/final_presentation.html` | Финальная презентация |
| `images/final.jpg` | Картинка финала |
| `audio/final_*.mp3` | Озвучки финала |

Если какого-то файла нет — платформа покажет заглушку «Материалы скоро появятся». Ничего не сломается.

## Шаг 8. Тестирование

1. Открой URL курса (из шага 3) в браузере
2. Введи тестовый email (например, `test@example.com`)
3. Открой День 1, посмотри все 6 кнопок
4. Открой «Домашнее задание», заполни, отправь
5. Проверь в Google-таблице — должен появиться новый лист `Homeworks_Level2` с твоей отправкой
6. В Apps Script редакторе вызови админ-функцию:
   ```js
   approveHomework("test@example.com", 1, "Отличная работа!")
   ```
7. В курсе: выйди и зайди снова с тем же email — должен открыться День 2

## Шаг 9. Управление ответами студентов

В Google-таблице в листе `Homeworks_Level2` ты увидишь все отправки:
- Колонка A: Дата
- Колонка B: Email
- Колонка C: День
- Колонка D: Текст ответа
- Колонка E: Статус (по умолчанию «На проверке»)
- Колонка F: Комментарий преподавателя

Чтобы одобрить/вернуть на переделку — два пути:

**Путь 1 (быстрый):** прямо в таблице измени значение в колонке E на «Одобрено» или «Переделать», в колонке F напиши комментарий. При следующем входе студент увидит обновление.

**Путь 2 (через скрипт):** в Apps Script редакторе вызови:
```js
approveHomework("student@email.com", 1, "Отличная работа!")
// или
requestResubmit("student@email.com", 2, "Попробуй дополнить ответ")
```

## Шаг 10. Кастомизация (опционально)

### Сменить цвет темы

В `index.html`:
```html
<meta name="theme-color" content="#8A2BE2">
```

В `manifest.json`:
```json
"theme_color": "#8A2BE2"
```

Сейчас стоит тот же фиолетовый `#8A2BE2`, что и в Курсе 1 (преемственность). Два бирюзовых акцента:
- Заголовок «Игра-медитация» (h1) — цвет `#00897B`
- Кнопка «Продолжить погружение» — градиент `linear-gradient(45deg, #00897B, #26A69A)`

Можешь поменять основной цвет или бирюзовые акценты на любые другие.

### Сменить иконки

Замени `icon-192.png` и `icon-512.png` на свои. Должны быть PNG указанных размеров.

### Добавить ссылку на Курс 1

В `index.html` после блока `<button id="instruction-btn">` можно добавить:
```html
<a href="https://goloka-gid.github.io/goloka-course/" target="_blank" style="display:block; margin-top:15px; font-size:13px; color:#666;">
  Пройти Курс 1 →
</a>
```
